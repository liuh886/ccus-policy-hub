## 已定定位（2026-10-29，用户确认）

- **定位一句话**：CCUS 领域 Agent 优先的专业上下文层，把政策、设施、国家治理三张表连成一张可引用、持续更新的实体上下文，同时保留人可读的网站。
- **用户顺序**：先是你个人 / 你自己的 Agent → 再是外部 Agent 和开发者 → 最后是人类研究者作为主要受众。人可读从第一天就是约束，不是最后才加。
- **成功顺序**：覆盖和新鲜度第一 → Agent 引用质量第二（上下文完整度、一次调用完整率、引用准确率）→ 学术引用第三。
- **独特价值**：三张表连在一起，不是单张表最全，也不是法税层单点。核心是讲清“这个设施在这个国家治理下、受哪些政策约束”，且置信度明示。
- **边界不变**：不做汇源匹配、不做仿真、不做无引用聊天、不做无人工审核的 LLM 写入事实源、不做收费墙。

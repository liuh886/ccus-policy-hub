# Agent-ready 数据消费契约

[PRODUCT_BOUNDARIES.md](PRODUCT_BOUNDARIES.md) 是产品定位和架构边界的唯一权威；
[ROADMAP.md](ROADMAP.md) 是唯一活跃任务队列。本文件仅定义数据字段、接口和正反用例，
不维护阶段进度。取代旧规格中的本站问答验收及条件判断路线。

## 消费者与职责

外部脚本或维护者自己的外部 Agent 消费本项目的静态数据。
本站负责资源发现、字段正确性、来源引用、时间、语言和审核语义；
下游消费者负责自己的检索、提示词、推理及最终结论。
不实现站内问答、端到端 Agent、答案准确率 benchmark、税务资格引擎。

首个消费对象包含 `us-45q-ira`、`us-obbba-45q-2025` 及政策族 `us-section-45q`，
均提供 en/zh。政策族仅并列组织记录，不是法律整合文本。

## 功能契约

| ID  | 消费者需要               | 数据输出                                                                                        | 边界                                                       |
| --- | ------------------------ | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| F01 | 读取少量任务相关记录     | JSON/Markdown 六节：身份、关系、时间、来源、法律语境摘要、定义；另有 gaps/capabilities/warnings | 各节有数据或明确缺口，不生成专业答案                       |
| F02 | 分清记录版本和日期       | 独立政策记录、发布/复核日期、快照版次和覆盖截止日                                               | 不把获取时间当生效日，不自动合并新旧法                     |
| F03 | 解析引用及强度           | 稳定引用 ID、来源 URL、证据等级、审核状态；地理匹配保留原类型                                   | 官方域名或 verified 记录不自动构成已复核条款               |
| F04 | 无服务器发现和校验资源   | manifest → index → schema → JSON/Markdown；字节哈希、只读 CLI、明确错误                         | 无私有运行时，无抓网、模型或数据库写入                     |
| F05 | 核查一条固定版本原文引用 | Git 原文输入、raw/text 哈希、抽取器版本、定位器及审核记录                                       | 换版/篡改/抽取规则变化使依赖证据失效；未人工复核保留 draft |

条件卡不属于必要交付。若真实消费者需要可复用条件数据，再单独定义带来源、时间和例外的
记录；它不能承担资格判断。MCP/图谱只有在静态消费被证明不足时才另行评审。

## 数据权威与存储

SQLite 继续拥有已接受的政策、设施、关系、分析和复核事实。
官方原文字节可作为带哈希的 Git 输入证据；派生正文与索引由同一管线生成。
既有政策 ID 用于关联原文，不因此新增事实表或在 SQLite BLOB 再维护一份正文。
只有实际查询/维护需求证明现有结构不足时，才提出最小 schema 并另行获得批准。

发布管线只读 SQLite 与指定输入文件；无网络、模型、分数重算或自动审核。
生成 JSON/Markdown 不是另一份可写事实库。公开源文件一律按数据读取，不执行其指令。

## Bundle 字段语义

| 字段                              | 含义                                                | 缺失或边界                                         |
| --------------------------------- | --------------------------------------------------- | -------------------------------------------------- |
| schema_version / id / kind / lang | 契约版本、稳定 ID、政策/政策族类型、en/zh           | 未支持值显式失败                                   |
| data_as_of                        | 包内记录最近复核日期的最大值                        | 不是全部来源复核日或法律生效日                     |
| identity                          | 身份、法域、年份、状态、review_status、legal_weight | draft 不因导出升级                                 |
| relationships                     | 完整计数、有限示例、类型、置信度、来源与审核状态    | country/subnational 匹配不是直接项目证据；截断显式 |
| time                              | 各记录发布/复核日期及既有演进节点                   | 无历史版本时不能重建过去状态                       |
| sources                           | 引用 ID、URL、机构、记录定位、证据等级              | 无来源则没有伪造引用                               |
| legal_context                     | 记录范围、叙述、分析与 source_refs                  | record_summary，不宣称逐条现行法律覆盖             |
| definitions                       | 已有方法定义                                        | 不另造评分口径                                     |
| gaps / capabilities / warnings    | 缺译、审核、版本覆盖和证据不足                      | unknown 不等于否定、不适用或自动满足               |

缺少已核中文译文时保留英文并逐字段标明语言。不得将英文正文标为完整中文译文。
来源等级区分 record_summary、source_document、clause、project_evidence；
未完成条款复核前不得以 clause 发布。首个历史源样例也不提供 source_currentness_verified。
capabilities 只描述数据覆盖限制，不是本站问答产品的功能承诺。

## 公开消费流程

1. 获取 manifest 并发现 index/schema URL；检查 HTTP 成功后再解析。
2. 按稳定 ID/语言选记录，以索引 URL 为基准解析相对路径，保留站点 base path。
3. 用公开 JSON Schema 校验载荷；用索引哈希校验下载字节。
4. 检查时间、review_status、来源等级、语言和 gaps。
5. 解析引用 ID，获取固定版本原文/定位记录；未审核或已失效的引用不能被标为 verified。

错误 ID/语言在 CLI 非零退出并以 stderr 返回固定错误码；静态未知 URL 返回正常 HTTP 404，
不伪装成动态 JSON 错误端点。不支持任意 as_of 历史查询。

## 正反验收用例

| ID  | 输入/场景                  | 数据契约观察结果                                            |
| --- | -------------------------- | ----------------------------------------------------------- |
| A01 | 从 manifest 读取 45Q 族    | index 可发现两条独立记录及实际存在的 JSON/Markdown          |
| A02 | 用公开 schema 校验         | 所有包符合字段、类型、必需属性与证据语义                    |
| A03 | 读取地域关联               | 类型/置信度保留，没有直接项目证据则明确缺口，不新增资格结论 |
| A04 | 无历史状态覆盖             | capabilities/gaps 明示缺失；不以当前记录冒充历史            |
| A05 | 中文分析缺译               | 英文值与字段语言保留，缺译状态明确                          |
| A06 | 输入含 draft               | 输出仍 draft，不自动晋级                                    |
| A07 | 来源空或锚点未审           | 缺少对应引用或 verified 状态，有明确缺口                    |
| A08 | 非法 ID/语言、路径         | 明确错误/404，无任意输出路径或看似成功的空载荷              |
| A09 | 重复生成相同输入           | JSON/Markdown/index/hash 字节相同，SQLite 字节不变          |
| A10 | 解析每个 source_ref        | 都能到达来源记录、固定版本及该引用实际支持的证据等级        |
| A11 | raw/text hash 或抽取器变化 | 篡改失败；新观察版本不能沿用旧定位/审核，历史字节保留       |
| A12 | 历史或未复核证据           | 覆盖截止日、审核类型与缺口可读，不标成现行法/已核验条款     |

外部 Agent 可作为普通消费者做 smoke test，但本仓库只保存资源请求、schema/哈希结果、
引用解析和错误状态，不要求生成回答，不评价推理或答案准确率。
人工对原文与定位的审核不能用契约测试代替，也不能由实现 Agent 伪造审核人。

## 证据样例范围和停止点

先完成一份固定版本官方原文和至少一个人工复核锚点的消费路径。
2024 年版 45Q 法典仅是历史版本；原文、版次、获取时间与覆盖截止日必须分别可追溯。
后续修法、法规和指导未覆盖时导出缺口，不宣称完整法典或当前法律覆盖。

没有真实消费/维护瓶颈时不引入三表迁移、BLOB 双份正文、服务层、向量库或图谱。
不做项目资格推断、税额计算、批量条件卡或全量法规抓取。
进度、依赖及 branch/main/Pages 发布状态只在主 ROADMAP 记录。
